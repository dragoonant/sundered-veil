# NOTICE

This is a personal, non-commercial fan project implementing the *game mechanics* of the
Star Wars: Unlimited trading card game so they can be played against an AI in a browser.
Game mechanics and rules are functional systems and are not subject to copyright.

It is a **testbed for those mechanics and for deck lists**, not a game to be played
through. The operator chooses BOTH sides before every match — their own deck and the
opponent's — from the same screen; there is no campaign, no progression, no unlocks, no
persistent player identity, and nothing to win beyond the match in front of you. Its
purpose is to answer "does this interaction resolve correctly, and how does this list play
against that one", which is why the AI opponent is measured against the deck matrix
(docs/ai.md) rather than tuned to be fun to beat.

What the project contains, and where:

- **Card, deck and trait names, and printed rules text of the published game** appear in
  exactly one file, `data/names-source.js`, generated by `tools/gen-source-names.mjs`
  from a public community card database. They are used to identify the cards whose
  mechanics are implemented, in the way a deck list or a rules reference names them. The
  player can switch them off in play; the game then shows the original names below. That
  file is loaded by the game only, never by the test suite.
- **Original names** for every card, leader, base, faction and setting live in
  `data/names-*.js` and `names.js` (theme: THEME.md). They are always loaded and are the
  fallback for anything the source file does not cover.
- **Card rules text is generated at runtime from mechanical effect data** whenever the
  printed text is switched off or absent. No published wording is stored anywhere except
  the generated file above.
- **All artwork is original**, AI-generated in an original style from prompts written for
  this project (`tools/art-prompts.json`, which describes subjects in original terms). No
  card image, logo or other artwork from the published game is included or imitated.
- **All audio is original**, AI-generated for this project.
- Import tooling reads mechanical fields (numeric stats, cost, type, keyword behavior,
  deck composition) from community databases; its intermediate files stay in a gitignored
  scratch directory.
